# Credits

The software combines contributions to PyAutoLens and its shared libraries. The list below recognizes development and contributed algorithms; historical contributions remain credited even where implementations have since changed.

## Developers

[James Nightingale](https://github.com/Jammy2211): PyAutoLens lead developer.

[Richard Hayes](https://github.com/rhayes777): PyAutoFit lead developer and model-fitting infrastructure.

[Aristeidis Amvrosiadis](https://github.com/Sketos): Interferometer Analysis.

[Amy Etherington](https://github.com/amyetherington) : Magnification, Critical Curves and Caustic Calculations.

Qiuhan He: NFW Profile Lensing Calculations.

[Jonathan Frawley](https://github.com/jonathanfrawley): Profiling, optimization and build server tools.

[Ashley Kelly](https://github.com/AshKelly): Developer of [pyquad](https://github.com/AshKelly/pyquad) for fast deflections computations.

[Xiaoyue Cao](https://github.com/caoxiaoyue): Analytic elliptical Power-Law Deflection Angle Calculations.

[Nan Li](https://github.com/linan7788626): Docker integration & support.

## Contributed code

[Andrew Robertson](https://github.com/Andrew-Robertson): Critical curve & caustic calculations.

Mattia Negrello: Visibility models in the uv-plane via direct Fourier transforms.

[Andrea Enia](https://github.com/AndreaEnia): Voronoi source-plane plotting tools.

Conor O'Riordan : Broken Power-Law mass profile.

## Further contributions

- [Coleman Krawczyk](https://github.com/CKrawczyk): JAX differentiation and critical-curve calculations in the shared galaxy library.
- [Samuel Lange](https://github.com/samlange04): ellipse and multipole tools, derived-parameter output and image-preparation interfaces.
- [Niek Wielders](https://github.com/NiekWielders): mass-profile implementations and configurable MGE settings.
- Hengkai Ding: shapelet and dPIE profile calculations.

See the [PyAutoLens contributor history](https://github.com/PyAutoLabs/PyAutoLens/graphs/contributors) and the [PyAutoGalaxy contributor history](https://github.com/PyAutoLabs/PyAutoGalaxy/graphs/contributors) for further code, documentation, testing and maintenance contributions. Names in commit history are not used to infer current roles or affiliations.
