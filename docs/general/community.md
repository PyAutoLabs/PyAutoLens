# Community

**PyAutoLens** is developed in the open, and this page is where the community meets it: getting help, contributing, and
the tools and material people have built on top of it.

## Get help & talk to us

Questions, help with your code or your analysis, and ideas go to the
[PyAutoLabs Discussions](https://github.com/orgs/PyAutoLabs/discussions).

Bug reports with a reproducer (a snippet, the traceback, your versions) go to the
[**PyAutoLens** issue tracker](https://github.com/PyAutoLabs/PyAutoLens/issues).

The Slack workspace is for collaborators, by invitation. Contact
[James Nightingale](https://github.com/Jammy2211) if you would like access.

## Contributing

Contributions are welcome. Before you start, read:

- The [**PyAutoLens** contributing guide](https://github.com/PyAutoLabs/PyAutoLens/blob/main/CONTRIBUTING.md).
- The [PyAutoLabs organisation-wide contribution guide](https://github.com/PyAutoLabs/.github/blob/main/CONTRIBUTING.md).
- The [Code of Conduct](https://github.com/PyAutoLabs/.github/blob/main/CODE_OF_CONDUCT.md).
- The [AI policy](https://github.com/PyAutoLabs/PyAutoScientist/blob/main/AI_POLICY.md): AI-assisted contributions are
  welcome under it.
- Workspace and tutorial notebooks: edit the `.py` scripts in the workspace `scripts` folders, not the notebooks. The
  `# %%` marker alternates code and markdown cells, and the notebooks are regenerated from the scripts.

If you would like hands-on help with a contribution, ask on the
[PyAutoLabs Discussions](https://github.com/orgs/PyAutoLabs/discussions).

## Community contributions

These are independent tools, tutorials, teaching material and the code behind papers that people have built on
**PyAutoLens**. They are maintained by their authors and are not endorsed, tested or supported by PyAutoLabs. Read each
project's own README and license before using it.

### Get listed

Post about your project in the [PyAutoLabs Discussions](https://github.com/orgs/PyAutoLabs/discussions) and the
maintainers will add it, or open a pull request editing this page (`docs/general/community.md`).

### PyAutoLens Visual Workbench

A local browser app for Mac and Windows for teaching and forward simulation, built on **PyAutoLens**. It provides
draggable 3D lens and source geometry with redshift planes, live parameter sliders, 31 scientific products
(deflections, magnification, critical curves and caustics, simulated images and more), PNG/FITS/CSV export and a
teaching quick-fit to simulated data. The interface is in English by default, with a Chinese UI available. Its scope is
forward simulation and teaching, not research inference.

- Repository: <https://github.com/SiriusFzh/PyAutoLens-Workbench>
- Author: [SiriusFzh](https://github.com/SiriusFzh)
