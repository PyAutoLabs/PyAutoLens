# Optional Tutorials

These tutorials expand on search choices and runtime after the main modeling chapter. Prior passing is retained as historical background.

The chapter contains the following tutorials:

[Tutorial: Alternative Searches](https://colab.research.google.com/github/PyAutoLabs/HowToLens/blob/main/notebooks/chapter_optional/tutorial_searches.ipynb)
\- Explore alternative search settings, optimisation and Markov chain Monte Carlo.

[Tutorial: Need for Speed](https://colab.research.google.com/github/PyAutoLabs/HowToLens/blob/main/notebooks/chapter_optional/tutorial_need_for_speed.ipynb)
\- Understand search effort, likelihood cost, JAX compilation, batching and hardware when assessing runtime.

[Historical Tutorial: Prior Passing](https://colab.research.google.com/github/PyAutoLabs/HowToLens/blob/main/notebooks/chapter_optional/tutorial_prior_passing.ipynb)
\- Read about older workflows that narrowed priors between searches. For the recommended component-separation approach, follow chapter 2 tutorial 6.
